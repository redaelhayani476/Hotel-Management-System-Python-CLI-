# Hotel Management System (Python CLI)

A simple console-based Hotel Management Application built using Python. This program allows hotel admins to manage rooms, check booking statuses, add new rooms, and process room reservations dynamically.

## Features
- 📋 **Show Rooms:** Display all available and booked rooms with their details.
- ➕ **Add New Room:** Dynamically add new rooms to the system with custom IDs and types.
- 🏨 **Book Room:** Search and reserve rooms based on their types.
- 🔄 **Interactive CLI:** Easy-to-use command-line menu interface.
